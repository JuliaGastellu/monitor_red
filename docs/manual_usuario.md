# Manual de Usuario

## Introducción

Este monitor de red es una herramienta diseñada para capturar y analizar el tráfico de su red en tiempo real, detectar posibles amenazas de seguridad y presentar los datos de forma clara a través de un dashboard web.

## Dashboard Web

Para acceder al dashboard, abra su navegador y vaya a la dirección que se muestra en la consola al iniciar la aplicación (por defecto, `http://localhost:8080`).

El dashboard tiene las siguientes secciones:

-   **Estadísticas Generales**: Muestra métricas clave sobre el tráfico de red en el último intervalo.
-   **Distribución de Protocolos**: Un gráfico que muestra el porcentaje de cada protocolo de red detectado.
-   **Últimas Alertas de Seguridad**: Una tabla con las alertas más recientes generadas por el sistema.

## Vista de Alertas

Haciendo clic en el enlace "Alertas" en la barra de navegación, puede acceder a una vista histórica de todas las alertas registradas en la base de datos.
